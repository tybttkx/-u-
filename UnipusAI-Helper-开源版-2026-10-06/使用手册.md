# U校园 自动答题助手 · 使用手册

> 适用于本目录（2026-10-06 开源版）
> 系统要求：**Windows 10 / 11（64 位）** · **Microsoft Edge** · **Python 3.10–3.12**（推荐 3.12；本包在 Windows 11 + Python 3.12.7 上实测通过）· 安装与使用全程需要联网
> 本目录的 `config.json` 里**账号与密钥都是空的**，照第三章填好再启动。

---

## 零、五分钟跑起来（已经装过环境的老手看这里）

```bat
:: 1) 装 Python 依赖（首次，见第二章；国内建议加镜像参数）
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

:: 2) 填好 config.json（账号 + 大模型 key，见第三、四章）
python config_editor.py

:: 3) 启动
python main.py
```

启动时程序会自己检查环境（Edge 浏览器、FFmpeg）。缺东西会弹一个菜单：

```
[1] 自动下载并安装 Edge 浏览器
[2] 自动下载并安装 FFmpeg（推荐）
[3] 将 FFmpeg 添加到系统 PATH（如已安装）
[4] 手动指定 FFmpeg 路径
[5] 显示详细帮助后退出
[Q] 退出程序
```

按提示选数字即可；装完**重新运行** `python main.py`。

## 一、它能做什么

1. **扫任务**：读取课程里的单元与任务列表（含必修 / 选修标记）。
2. **找答案**：先查本地题库 `knowledge/`；没命中再按题型走专门策略（跟读、括号汉译英、排序、看图配对…），最后才交给大模型，并可联网搜索作补充。
3. **作答与提交**：自动填写并按页面上的 提交 / 发布 / 保存 按钮提交，再读「答题小结」判分。
4. **回流题库**：判分达标（默认 ≥ 80 分）或页面公布标准答案时，把答案写回 `knowledge/`；下次遇到同一题**直接命中题库**。

**它不会做的事**：不替你登录别人的账号、不绕过平台风控、不改动平台数据。只在本机操作浏览器。

## 二、安装（按顺序做）

### 2.1 装 Python

**方式 A：winget（Win11 / 新版 Win10 自带）**

```bat
winget install -e --id Python.Python.3.12
```

**方式 B：官网安装包**

1. 打开 <https://www.python.org/downloads/windows/>，下载 **Windows installer (64-bit)**；
2. 安装第一步**务必勾选 `Add python.exe to PATH`**，再点 Install Now。

**验证**（装完新开一个 CMD 窗口）：

```bat
python --version
pip --version
```

两条都打印版本号才算成功。若提示"不是内部或外部命令"：

- 重新运行安装包 → Modify → 勾上 Add to PATH；或
- 用 `py -3.12` 代替 `python`（Windows 自带的启动器）。

### 2.2 装依赖

在本目录（有 `main.py` 的那一层）打开 CMD，执行：

```bat
cd /d 本目录的完整路径

:: （可选，推荐）建一个独立环境，避免和别的项目打架
python -m venv .venv
.venv\Scripts\activate

:: （推荐先做）装 CPU 版 PyTorch，约 200–300MB
:: 不先装的话，pip 会拉带 CUDA 的版本，2GB 以上
pip install torch --index-url https://download.pytorch.org/whl/cpu

:: 装项目依赖（国内建议加清华镜像）
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

`requirements.txt` 里各是干什么的：

| 包 | 用途 |
| --- | --- |
| `selenium` | 驱动 Edge 浏览器（4.6+ 会自动下载匹配的浏览器驱动） |
| `openai` | 调用大模型接口（OpenAI 兼容格式） |
| `openai-whisper` | 本地语音转文字（听力 / 视频题、看视频认人） |
| `numpy<2.0.0` | whisper 的依赖，锁 1.x 版本 |
| `PyQt5` / `PyQt-Fluent-Widgets` | 图形界面 |

> 语音识别必须配套安装 **FFmpeg**（下一节），whisper 靠它解码音频。

### 2.3 装 FFmpeg

三种方式**任选其一**。

**方式 A：让程序帮你装（最省事，约 130MB）**

直接 `python main.py` → 环境检查不通过时会弹菜单 → 选 `[2]`。它会下载、解压到 `%LOCALAPPDATA%\ffmpeg`，并自动写进用户 PATH，然后要求你重新运行程序。

**方式 B：winget**

```bat
winget install -e --id Gyan.FFmpeg
```

装完**新开**一个 CMD（旧窗口读不到新的 PATH）。

**方式 C：手动**

1. 下载 <https://www.gyan.dev/ffmpeg/builds/ffmpeg-release-essentials.zip>（或 <https://ffmpeg.org/download.html>）；
2. 解压到 `C:\ffmpeg`，确认存在 `C:\ffmpeg\bin\ffmpeg.exe` 与 `ffprobe.exe`；
3. 把 `C:\ffmpeg\bin` 加进 PATH，二选一：
   - 重新 `python main.py`，在环境检查菜单里选 `[3]`（程序会把已装的 FFmpeg 写进用户 PATH）；
   - 手动：`设置 → 系统 → 系统信息 → 高级系统设置 → 环境变量` → **用户变量**里的 `Path` → 新建 → 填 `C:\ffmpeg\bin` → 一路确定。

> ⚠ 不要在 CMD 里用 `setx PATH "%PATH%;C:\ffmpeg\bin"`：`setx` 会把超过 1024 字符的 PATH 截断，容易搞坏环境变量。用上面的图形界面或程序菜单。

**验证**（新开 CMD）：

```bat
ffmpeg -version
ffprobe -version
```

能打印版本号（如 `ffmpeg version 7.x`）即成功。

### 2.4 装 Edge 与浏览器驱动

**Edge 浏览器**（Windows 10/11 一般自带）：

```bat
winget install -e --id Microsoft.Edge
```

或到 <https://www.microsoft.com/edge> 下载；也可以让程序菜单 `[1]` 帮你下载安装。

**浏览器驱动**：不用手动装。`selenium` 4.6 以上在**首次运行**时会自动下载与你的 Edge 版本匹配的 `msedgedriver`（需要联网，缓存到 `%USERPROFILE%\.cache\selenium`）。

自动下载失败时（常见于公司网络 / 代理），手动兜底：

```bat
:: 1) 查本机 Edge 版本号
reg query "HKEY_CURRENT_USER\Software\Microsoft\Edge\BLBeacon" /v version

:: 2) 到官网下载"与上一步大版本号相同"的 x64 驱动
::    https://developer.microsoft.com/microsoft-edge/tools/webdriver/

:: 3) 解压得到 msedgedriver.exe，放进一个 PATH 目录里，例如：
mkdir C:\edgedriver
::    把 msedgedriver.exe 复制进 C:\edgedriver
::    再把 C:\edgedriver 加进用户 PATH（同上：图形界面里改，别用 setx）
```

> 升级 Edge 后如果突然报驱动不匹配，把 `%USERPROFILE%\.cache\selenium` 删掉再运行，让它重新下载。

## 三、配置：`config.json`

两种改法：**图形界面** `python config_editor.py`（推荐，保存时会自动备份成 `config.json.bak`），或直接用记事本编辑 `config.json`。

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `username` / `password` | 空 | U校园 AI 版账号与密码 |
| `url` | 已填好 | 登录入口，不用改 |
| `token_full` | 空 | 可选的长期令牌。填了账号密码就不需要它 |
| `api_key` | 空 | 大模型密钥。也可写 `env:变量名`（如 `env:DASHSCOPE_API_KEY`），从环境变量读，不用把 key 写进文件 |
| `base_url` | 阿里云百炼 | OpenAI 兼容接口地址。默认 `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| `model` | `qwen3.8-omni-flash` | 主控模型名，从服务商控制台复制准确名称 |
| `vision_model` / `vision_model_2` | 同上 / `qwen3.8-max` | 看图题（图片配对、看视频认人）用的视觉模型；两个模型投票，更可信 |
| `max_tokens` / `temperature` | `4096` / `0.3` | 生成参数，默认即可 |
| `whisper_model` | `base` | 本地语音识别模型：`tiny`（最快最小）/ `base`（默认）/ `small`（更准，约慢 3 倍）/ `medium`、`large`（更准更慢更吃内存） |
| `knowledge_enabled` | `true` | 是否启用本地题库 |
| `knowledge_textbook` | `auto` | `auto` = 按页面自动识别教材；也可写死教材名（如 `新编大学英语 综合教程3`） |
| `knowledge_min_confidence` | `medium` | 题库最低置信度：`low` / `medium` / `high` |
| `knowledge_verify_wordbank` | `true` | 选词填空是否要求页面词库一致才用本地答案 |
| `harvest_verified_answers` | `true` | 判分达标后是否把答案收录回题库 |
| `harvest_min_score` | `80` | 收录门槛（小结得分） |
| `search_enabled` | `true` | 题库没命中时是否联网搜索作补充 |
| `search_api_key` | 空 | 联网搜索密钥（博查 AI，可选） |
| `mic_auto_grant` | `true` | 录音题运行期间自动放行麦克风，退出后恢复系统设置（等价于你在"设置 → 隐私和安全性 → 麦克风"里点一下"允许"） |
| `strict_submit_check` | `false` | `false` = 有题没答也照常提交；`true` = 有题没答就不提交 |
| `debug_mode` | `false` | 调试日志开关 |
| `debug_port` | `9333` | Edge 远程调试端口，供 `python 抓页面.py` 排障用；**多开时每个副本要改成不同的值**（9333 / 9334 / 9335） |

> ⚠ 填了真实账号的 `config.json` 以及自动生成的 `config.json.bak*` **都是明文凭据**，不要打包分享、上传网盘或提交到仓库。

## 四、申请密钥（两个都要自己注册，都是可选的组合）

### 4.1 大模型（必填一个，默认阿里云百炼）

以**阿里云百炼（DashScope）**为例：

1. 打开 <https://bailian.console.aliyun.com/>，用阿里云账号登录（需实名认证）；
2. 在「模型广场」找到要用的模型并开通（记下**准确的模型 ID**，填进 `config.json` 的 `model`）；
3. 左侧「API-KEY」→ **创建我的 API-KEY** → 复制（`sk-` 开头，只完整显示一次）；
4. 打开 `config.json` 填三处：

```json
"api_key": "sk-你的密钥",
"base_url": "https://dashscope.aliyuncs.com/compatible-mode/v1",
"model": "控制台里的模型 ID"
```

也支持任何 **OpenAI 兼容**服务（DeepSeek、硅基流动、Kimi、本地 vLLM 等）：把 `base_url` 和 `model` 换成对方的即可，`api_key` 填对方的 key。

**验证密钥与模型**（会分别测文本、视觉、图片输入三项）：

```bat
python 检查模型.py
```

退出码 `0` = 三项全通过；`1` = 缺 key 或某项没过（报错信息里会写明原因）。

### 4.2 联网搜索（可选）

题库没命中的题，先联网搜一下再交给大模型，命中率更高。

1. 打开 <https://open.bochaai.com/> 注册并创建 API KEY；
2. 填进 `config.json` 的 `search_api_key`；也可以不写进文件，改用环境变量 `BOCHA_API_KEY`；
3. 不想用就把 `search_enabled` 设为 `false`。

## 五、虚拟声卡与跟读题（VB-Cable，做跟读题必装）

跟读题要求"录进去的声音就是标准读音"。程序的做法是把**示范音的数字回环**当成麦克风输入，所以需要一台虚拟声卡。

### 5.1 安装 VB-Cable（推荐）

1. 到 <https://vb-audio.com/Cable/> 下载 `VBCABLE_Driver_Pack*.zip`（约 1MB）；
2. 解压 → 右键 `VBCABLE_Setup_x64.exe` → **以管理员身份运行** → 点 **Install Driver**；
3. 看到 `Installation Complete and Successful` 后**重启电脑**；
4. 重启后自检：右下角喇叭图标右键 → 声音设置 → 更多声音设置 →
   - 「播放」标签里应出现 **CABLE Input**
   - 「录制」标签里应出现 **CABLE Output**

**验证程序能否自动切换**：跑一道跟读题，日志里出现

```
跟读题：已自动打开 VB-Cable（录音题专用）
VB-Cable：播放 ✔ 录音 ✔
```

就是通了。跑完会自动切回：

```
真实设备：播放✔ 录音✔
```

### 5.2 不想装 VB-Cable：用「立体声混音」兜底

Realtek 声卡一般自带。启用方式：声音设置 → 更多声音设置 → **录制** → 右键空白处 → 勾选"显示禁用的设备" → 右键 **立体声混音** → 启用。

程序会先找 VB-Cable，找不到再按名字找"立体声混音"，这时**只切录音设备、播放保持原样**（日志：`VB-Cable：未找到，改用「立体声混音」当录音输入`）。回环质量因机型而异，不如 VB-Cable 稳。

### 5.3 手动填设备 ID（前两招都失效时的最后一招）

程序认设备有两个来源：先用内置设备 ID（作者机器），认不出再**按设备名找**（设备名先读 COM 属性，读不到就查注册表 `HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\MMDevices\Audio\...`，所以一般都能读到）。只有连名字都和默认关键词（`CABLE Input` / `CABLE Output` / `立体声混音`）对不上时，才需要动代码：把 `audio_route.py` 顶部的 `CABLE_IN_ID` / `CABLE_OUT_ID` 换成你机器上的设备 ID。

取设备 ID 的办法（PowerShell，只读）：

```powershell
Get-PnpDevice -Class AudioEndpoint | Select-Object FriendlyName, InstanceId
```

输出里 `InstanceId` 形如 `SWD\MMDEVAPI\{0.0.1.00000000}.{c6b906d6-...}`，**去掉 `SWD\MMDEVAPI\` 前缀**剩下的 `{0.0.1.00000000}.{c6b906d6-...}` 就是要填的设备 ID（播放端是 `{0.0.0.…}`，录音端是 `{0.0.1.…}`）。

> 程序每次进录音题都会**记下切换前的默认设备**，跑完（正常退出）自动切回；被强制结束进程时，`use_real_devices` 会在下次运行时按"扬声器 / 麦克风"这类名字把真实设备拉回来。

### 5.4 跑录音题的注意事项

- 录音期间**别让电脑播放其它声音**（视频 / 音乐 / 会议 / 另一个副本也在跑），回环会把它们一起录进去；
- **别静音**输出；
- 如果发现"别的软件没声音了"，多半是默认设备还停在 CABLE 上：声音设置里把「播放」改回扬声器、「录制」改回麦克风即可。

## 六、启动与使用

```bat
:: 正常启动（会自动做环境检查）
python main.py

:: 环境检查已通过、想跳过检查直接启动
python main.py --skip-check

:: 图形化配置编辑器（填账号、密钥、题库开关等）
python config_editor.py

:: 排障：连上程序的 Edge 调试端口，dump 当前页面
python 抓页面.py
```

**界面怎么用**：左侧「任务」列表勾选要做的任务（支持全选 / 必修 / 清空）→ 点「快速处理当前页」或开始处理 → 右侧「控制」区显示进度与当前任务 → 下方「日志」实时打印每一步（找答案、填答案、判分、收录题库）。随时可以「停止」，退出点「安全退出软件」。

**日志**：界面日志同时写入 `logs\ucampus_日期_时间.log`，出问题先看这里。

**首次运行会慢**：要下载 Whisper 语音模型（`base` 约 140MB，存到 `%USERPROFILE%\.cache\whisper`）和浏览器驱动。离线机器请提前把这两个目录拷过来。

## 七、出问题怎么查（三步）

1. **看日志**：`logs\` 里最新那个文件；界面下方日志面板也一样。每道题用了哪条路径（题库 / 搜索 / AI / 策略）都逐行写着。
2. **看环境**：重新 `python main.py`，让环境检查再跑一遍；或者 `ffmpeg -version`、`python --version`、`python 检查模型.py` 各跑一次。
3. **看页面**：程序启动时会开一个调试端口（`debug_port`，默认 9333）。保持程序运行，另开一个 CMD 执行 `python 抓页面.py`，会把当前页面的文字和关键元素打印出来，便于定位"页面变了导致的找不到按钮/题"。

跑两套回归测试也能快速判断代码本身有没有问题（**修改过代码后建议跑一遍**）：

```bat
python test_knowledge_base.py
python test_smoke.py
```

两套都应打印 `全部/passed` 且退出码为 0（本包出厂时：`50/50 passed`、`41/41 passed`）。

## 八、常见问题

**Q：`python` 命令找不到？**
装 Python 时没勾 Add to PATH。用 `py -3.12` 代替，或重装勾上。

**Q：`pip install` 很慢 / 超时？**
加国内镜像：`pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`。

**Q：装了 FFmpeg，程序还说找不到？**
PATH 改完必须**新开** CMD / 重启程序。验证 `ffmpeg -version` 能打印版本号。

**Q：启动时报 Edge 驱动相关错误？**
删掉 `%USERPROFILE%\.cache\selenium` 再运行，让 Selenium 重新下载；仍失败就按 2.4 节手动放 `msedgedriver.exe`。

**Q：语音识别（听力题）没有结果？**
先确认 `ffmpeg -version` 正常、`whisper_model` 文件已下载（首次运行会下）；再看日志里的「加载 Whisper 本地模型」有没有报错。若识别错字多，把 `whisper_model` 改成 `small`（更准但约慢 3 倍）。

**Q：题库里明明有这题，为什么没用？**
按日志里的原因逐个排查：`未匹配到小节`（找错小节）/ `候选小节无法区分`（同名小节并列）/ `无法用页面词库验证`（词库不符）/ `教材命中：<别的书>`（教材识别错）。另外收割写入的答案要**重启或热重载后**才会进内存。

**Q：某页 0 题？**
说明解析层没认出这页，兜底策略会接管（日志 `兜底策略接管：…`）。若仍 0 题，请把日志里 `找到 N 个题目容器` 那几行发出来。

**Q：大模型请求失败？**
看日志里的报错原文：`401` 一般是 key 不对；`429` 是限流；余额不足会明确提示欠费。先用 `python 检查模型.py` 排除 key / 模型名问题。

**Q：能同时开多个账号吗？**
可以。复制多份目录，各自填账号，并把 `debug_port` 改成互不相同的值（9333 / 9334 / 9335）。题库可以共用（见第十章）。**不要同时跑跟读题**（默认音频设备会互相抢）。

**Q：跟读题录音没声音 / 分数低？**
见第五章：装 VB-Cable、录音时别放其它声音、别静音。

**Q：麦克风权限被改了？**
程序只在运行期间把浏览器（msedge.exe）的麦克风权限写成"允许"，退出时写回原值；即使被强杀，下次启动也会自动恢复。全部逻辑在 `mic_permission.py` 顶部有说明。

## 九、题库：格式与手工补充

题库就是 `knowledge/` 里的 Markdown 文件，一本书一个文件，纯文本，改完存盘即用（程序启动时加载）。支持两种写法：

**写法一（单级，适合有 `1-6` 编号的教材）**

```markdown
# <教材名> — Unit N <单元主题>

## 1-6 Read and practice · Banked cloze

词库：adequate / assigned / closing / …
1. finals
2. due
```

**写法二（两级，适合 Section 结构的新视野系列）**

```markdown
# <教材名> — Unit N

## Section A · Reading comprehension

### Understanding the text

1) On the "offline days" …
2) The little devices change …
```

要点：

- 小节名要**与页面显示的逐字一致**，这是命中率的根基；
- 两级写法下，程序要求"页面名 + 任务名"都对上才认这一节（避免 Section A / B 同名任务串答案）；
- 把新 `.md` 放进 `knowledge/<系列名>/` 就会自动被加载，**不用改代码**；
- 想确认写了多少、还缺哪些，看 `knowledge/INDEX.md`；更细的命中规则（教材识别、词库校验、题目指纹、置信度）见 `README.md` 的「本地题库知识库」章节。

> 题库内容是个人整理的公开答案，**请自行核对准确性**；平台答案如有更新，旧答案可能失效。

## 十、多开、共用题库

```bat
:: 复制一份目录给第二个账号（例如 账号B）
xcopy "本目录" "D:\UnipusAI-Helper-账号B" /E /I /H /Y

:: 两个副本各自改 config.json 的账号与 debug_port（9333 / 9334）
```

想让两个副本共用一份题库（避免各写各的）：

```bat
:: 先删掉或改名 账号B 里原有的 knowledge 目录，再建目录联接
mklink /J "D:\UnipusAI-Helper-账号B\knowledge" "本目录\knowledge"
```

> `mklink /J` 的目标目录**必须不存在**（先删掉/改名）。目录联接是 Windows 自带功能，不需要管理员权限（建 /J 联接时）。
> 共用题库时两个副本会同时写同一个文件，收割的 `.bak` 备份可能互相覆盖——不放心就各用各的题库。
